DEX BUDGET - FREE IPHONE WEB APP

Upload all five files from this folder to the root of a public GitHub repository named dex-budget. In the repository, go to Settings > Pages, select Deploy from a branch, choose main and /(root), then Save. Wait for GitHub Pages to publish. Your app URL will usually be https://YOUR-USERNAME.github.io/dex-budget/ .

On your iPhone, open that URL in Safari. Tap Share > Add to Home Screen > Add. Launch Dex Budget from your home screen.

Only your daily earnings need to be entered. Set-aside and savings figures are estimates based on your editable settings. History is stored locally on the device; use Export backup regularly. The app does not sync between devices. Hosting the app on a public repository makes its source code public, but your locally stored financial entries are not uploaded to GitHub.
